# Creative Technology India 🇮🇳

A curated directory and open index of organizations, studios, experimental labs, academic institutions, festivals, and practitioners working at the intersection of art, design, science, and computing across India.

🌐 **Live Website:** [https://creative-tech-india.github.io/](https://creative-tech-india.github.io/)

---

## 🧭 Directory Index

The directory captures initiatives across key disciplines:
- **Organisations & Labs**: Research hubs, university labs, and non-profits
- **Studios**: Commercial, experiential, and interactive technology studios
- **Communities**: Algorave groups, live coders, and creative computing collectives
- **Programs & Residencies**: Fellowships, incubators, and grants
- **Events & Festivals**: New media art, sound, and technology festivals
- **Artists & Practitioners**: Independent new media and creative tech artists
- **Awards & Platforms**: Design and technological excellence platforms

---

## 🤝 How to Contribute & Update Entries

This directory is an open community initiative. If you run a studio, collective, lab, or event—or noticed any inaccurate or outdated details (apologies if so, we continuously aim to improve and keep listings accurate):

- **Email Directly:** Send entry details, updates, or corrections to **[hello@creativetechindia.net](mailto:hello@creativetechindia.net)**.
- **Submit via Issue:** [Open an Issue](https://github.com/Creative-Tech-India/creative-tech-india.github.io/issues/new) on GitHub.
- **Submit via Pull Request:** Add or update an entry in [`data/directory.json`](data/directory.json) and open a PR.

## 💻 Local Development

Built with [Next.js](https://nextjs.org/) (App Router), TypeScript, and React.

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🚀 Deployment (Vercel)

This project is optimized for deployment on [Vercel](https://vercel.com):

1. Import this GitHub repository into your Vercel account.
2. Vercel automatically detects Next.js with zero configuration needed.
3. Click **Deploy**. Each commit and pull request will receive automatic preview and production deployments.
